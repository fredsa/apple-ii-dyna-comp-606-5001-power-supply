# Apple II 605-5703 (DynaComp 606-5001) Power Supply 110v

- KiCad schematic reverse-engineered by Fred Sauer in 2025, 2026.

- Part numbers and compontent layout updated to match power supply schematic
  published in _The Apple II Circuit Description_ (reprint of
  _Apple II Reference Manual 1981_), except for differences indicated by dotted
  outlines marked `diff`.

- Refer to [U.S. Patent 4,130,862](https://patents.google.com/patent/US4130862A)
  for an explanation of key design features of this power supply.

- KiCad and PDF schematic can be found in the `Dyna-Comp-606-5001-KiCad/`
  folder.
